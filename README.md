# teste-mutacao

obertura de código significa apenas que as linhas do programa foram executadas durante os testes. Porém, isso não garante que a lógica esteja correta. No teste fraco, a função era executada, mas nenhum valor era validado. Mesmo com a regra sabotada, o teste continuava passando. Já o teste de mutação verifica a qualidade dos testes através da criação de mutantes, que são alterações artificiais no código. Quando os testes conseguem detectar essas alterações, o mutante é morto. Caso contrário, ele sobrevive, indicando falhas nos asserts. Portanto, o Mutation Score mede a eficácia real dos testes, enquanto a cobertura mede apenas execução de linhas de código.
